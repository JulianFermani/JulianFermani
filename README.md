Estudiante de **4.º año de Ingeniería en Sistemas de Información en UTN FRVM**, desarrollador web y SysAdmin.

Actualmente trabajo en infraestructura y administración de sistemas en la **Municipalidad de Villa María**, desarrollo web en **CICOM — UTN Facultad Regional Villa María** y, en el poco tiempo libre que me queda, desarrollo **[DondeAnda](https://dondeanda.com.ar)**, una plataforma para consultar colectivos interurbanos en tiempo real.

## 🧠 Sobre mí

Mi experiencia actualmente cruza dos mundos que me interesan mucho: **desarrollo de software e infraestructura**.

Como desarrollador trabajo principalmente con aplicaciones web, APIs, diseño modular y buenas prácticas de arquitectura. Como SysAdmin trabajo con servidores Linux, redes, servicios, virtualización, backups y resolución de problemas de infraestructura.

También disfruto desarrollar proyectos propios donde puedo recorrer todo el ciclo de vida de un producto: desde detectar un problema y diseñar la solución hasta programarla, desplegarla y mantenerla funcionando.

## 🚀 Key Projects

### 🚌 [DondeAnda](https://dondeanda.com.ar)

Aplicación web para visualizar colectivos interurbanos de Córdoba en tiempo real sobre un mapa interactivo.

Permite consultar ubicación, línea, empresa, destino, sentido, puntualidad y última actualización de los colectivos disponibles.

**Stack:** Svelte · Node.js · Fastify · Tailwind CSS · Leaflet · Docker

---

### 🤖 [Chat Pack](https://github.com/JulianFermani/chat-pack)

El proyecto explora arquitectura modular, separación de responsabilidades y conceptos de Clean Architecture.

**Stack:** TypeScript · NestJS · Node.js
